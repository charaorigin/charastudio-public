## v1.0.0 - 2026-06-03

+ [Added] Character creation, editing, deletion, and complete information management (basic info, background story, personality, appearance, life events, relationships, metadata).
+ [Added] Preset + custom tag system (personality traits, strengths/weaknesses, habits, body type, hairstyle, skin tone, eye color, features, accessories, etc.) with quick filtering.
+ [Added] Character relationship management with add, edit, and delete capabilities.
+ [Added] AI-assisted character creation: auto-generate background stories, personality analysis, relationship suggestions, and character concept tips.
+ [Added] Markdown editor with structured field parsing.
+ [Added] Character gallery: upload local images (JPG, PNG, WebP, max 10MB per file).
+ [Added] AI image generation for characters: two-step generation (LLM prompt generation -> image model output), supporting portrait, four-view, expressions, poses, story nodes, and more, with art style, aspect ratio, and generation parameter controls.
+ [Added] Gallery management: batch delete, set as cover, preview.
+ [Added] Real-time character chat with streaming responses for a smooth experience.
+ [Added] Multi-session management: create new sessions, switch between sessions, delete sessions.
+ [Added] Chat export functionality.
+ [Added] Character profile import/export for easy backup and sharing.
+ [Added] Chat mode switching: roleplay and story narration modes.
+ [Added] Model selection: specify the language model for generation.
+ [Added] Generation parameter controls: Temperature, Max Tokens, TopP, minimum output length.
+ [Added] System prompt template editor: view, edit, and reset system prompts for deep customization of character behavior.
+ [Added] Model management: configure language models (LLM), image generation models, and ComfyUI models with OpenAI-compatible API, supporting local or cloud services.
+ [Added] Account system: registration, login, profile management.
+ [Added] Data export: export user data for backup.
+ [Added] Internationalization: Chinese (Simplified), English, Japanese with real-time switching without restart.
+ [Added] UI style preference customization.
+ [Added] Automatic update detection and notifications.
